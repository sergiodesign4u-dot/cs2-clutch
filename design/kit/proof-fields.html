When to use

Proof fields stand where a round is checked: on Provably fair, to say what a proof is made of before anyone types into the Verify form; on a round's public page, to hand over the round's own values so a stranger can recompute it without an account. Provable fairness is built so the product's own numbers are checkable (design principle 1, D-14); the fields are those numbers, in words, never a seal.

Rule and anti-rule

Use it

The parts of a round proof, or one round's values with Copy, on the provably fair blue.

Take another component

Typing values in to recompute a round is the Verify form. A round's whole proof with its state, its scope line and its act is the Proof block, which holds these fields. One hash before an open is a Copyable value. A line of key and value elsewhere is a Key-value line.

States

No states: it is not interactive. A Copy act inside --values keeps the Copyable value's own states, and the copied value's word is set by the product's script there.

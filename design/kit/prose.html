Responsible play

When to use

Prose is the page's own text: the explanation a person reads once and the SEO layer that sits among it. It is not for a line that qualifies a figure, which is a Note line, and not for a value, which is a Figure or a Key-value line. It is written in the voice's own register: a straight answer from someone on the scene, the number rather than the superlative.

Rule and anti-rule

Use it

Four limits you set yourself, at Responsible play, as .prose--text. The catalogue's opening paragraph, as the lead.

Take another component

One line under a block is a Note line. A question that opens its answer is a Disclosure. A link that stands alone is a Text link; a link inside a sentence stays a plain link here.

States

No states: it is not interactive. A link inside it is the page's own link, and a standing link is the Text link's, with its states.

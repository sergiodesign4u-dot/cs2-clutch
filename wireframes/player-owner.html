This is what the account has won, not what it holds now. An item sent to Steam or sold back for coins stays on this list, with where it went in place of a value.

What this page is

Every skin this account has won from a case, newest first, each one with the round behind it. Values are in coins, and what one coin is worth in real money is not published yet.

The public id
Not the id on the account's own profile. That one is what support and an appeal refer to, and printing it here hands a stranger the string an impersonation would use.
What the public id looks like is not decided. The recommendation is that it is opaque: the live product's is a six digit number a reader can count down from, which makes the registered account total readable from outside.
No total
There is no sum of what this account has won, no rank, and no position against anyone else. A shelf with a total on it is a leaderboard with one row.
Other modes
Case battles, gunfights and upgrades are not in this round, so there are no counters for them and no history tabs for them. When one arrives it brings its own count and its own list.
How you got here
From a drop in the running strip or from a result someone shared. There is no directory and no search, so this page is reached by a link and not by looking a person up.

You cannot turn this page off. It exists for every account and there is no setting for it here or in Settings. Whether an account will ever be able to hide it is not decided, and until it is, no control for it will be drawn.

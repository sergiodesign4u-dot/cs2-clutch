The public id
Not the id on the account's own profile. That one is what support and an appeal refer to, and printing it here hands a stranger the string an impersonation would use.
What the public id looks like is not decided. The recommendation is that it is opaque: the live product's is a six digit number a reader can count down from, which makes the registered account total readable from outside.
No total
There is no sum of what this account has won, no rank, and no position against anyone else. A shelf with a total on it is a leaderboard with one row.
Other modes
Case battles, gunfights and upgrades are not in this round, so there are no counters for them and no history tabs for them. When one arrives it brings its own count and its own list.
How you got here
Not from a drop in the running strip and not from a shared result: this account has produced neither. Someone gave you this address, or it was typed. There is no directory and no search, so this page is reached by a link and not by looking a person up.

Whether an account can hide this page is not decided. Today it exists for every account and cannot be turned off.

# CJM evidence ledger

Every quote behind `cjm-as-is.md`, in one place, so that any count in that file can be checked from this repository alone.

**Why this file exists.** The step 6 critique found the same defect from two instruments at once: the counts in `cjm-as-is.md` came from a real mining pass, but the mining reports lived in a session and never entered the repository. Codex, reading a snapshot, could not verify a single "pattern of N", and neither could any person opening the file later. A number that cannot be checked is a number on trust.

**The rule this ledger imposes on the map.** A count in `cjm-as-is.md` may not exceed the number of quotes listed here. Where the mining pass counted more than the ledger holds, the map's number has been reduced to the ledger and the wider pass total is named as a pass total, never as evidence weight.

**Method limits carried from `cjm-as-is.md`.** Trustpilot brand pages were captured in a live browser on 10 August 2026, screenshots in `research/screens/cjm/`. A Trustpilot brand page is not a sample: key-drop shows an aggregate of 4.3 with a first page that is almost entirely one star, skin.club shows 3.6 with a first page that is entirely five stars. Proportions are therefore never claimed. Reddit was unreachable by every route tried and contributes nothing. Steam Community and HLTV substitute for it. Forum threads select for the moment something went wrong.

**How to read a row.** Quote, then platform being discussed, then star rating where the source has one, then date, then source. `[q-mode]` marks an HLTV excerpt pulled in quote-extraction mode rather than full transcription: genuine, shorter, surrounding context unverified.
